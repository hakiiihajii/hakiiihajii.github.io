# Hakima Haji — Portfolio Website

A responsive, single-page portfolio made with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a public GitHub repository (e.g., `portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, `main`, and `/ (root)`; save.
5. Your site will typically appear at `https://hakiiihajii.github.io/portfolio/` once deployment finishes.

## Customize
Edit the text in `index.html`, colors in `styles.css`, and add verified project repository links or a CV download link when available.

Note: Project descriptions are based on prior discussions; review them before publishing. The site intentionally does not claim certifications or employment history.
